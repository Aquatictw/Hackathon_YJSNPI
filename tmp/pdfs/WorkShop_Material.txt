Development environment

firefox in host controller to connect vscode server with password to

persist volume which folder is /home/debugger/project to avoid
file missing once the container stop or crash.

the measurement and generate test results to data log stream.

production run simulation, the Edge server will pull the
image from AUS and start the image to wait test result event
from host controller.

===== PAGE 23 =====
How to trigger SmarTest load program and run manually
• When user want to debug application which is using ONEAPI to receive real time result
from SmarTest, user need to run the program manually.
• runTp.sh can help user to load test program/ run program manually or run production simulation.
– Usage: ./runTp.sh {load|eng_run|prod_run} [loop_count]
– “./runTp.sh load” will start SmarTest and load the target test program.
– “./runTp.sh eng_run 2” will run test program two times.
– “./runTp.sh prod_run” will run production simulation.
Two steps to trigger program run.
1. If program is not loaded, run ./runTp.sh load first.
2. If program is loaded, run ./runTp.sh eng_run 1

Docker file example for image build
▪ What is docker images
• A Docker image is a read-only template that contains everything needed to run an application:
• Application code
• Runtime (Java, Python, Node.js, etc.)
• Libraries and dependencies
• Environment variables
• Configuration files
• Think of it like a snapshot or blueprint of an application.
▪ Docker file is defined how to build the image to support user’s requirement.
• Example:
Base image
Change directory in image
Copy file to image
Set environment variable in image
Run the script in images
